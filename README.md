WATI is an official WhatsApp Business Platform that provides a shared team inbox, no-code chatbot builder, broadcast campaigns, and CRM integrations for businesses communicating with customers over WhatsApp. The platform offers a tenant-scoped REST API for sending template and session messages, managing contacts, and integrating with external systems. WATI APIs use Bearer token authentication tied to each customer's WATI workspace.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/wati/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/wati/refs/heads/main/apis.yml)

## APIs

### WATI WhatsApp Business API

Tenant-scoped REST API for sending WhatsApp template and session messages, managing contacts, assigning operators, and orchestrating chatbot flows. Uses Bearer token authentication with per-workspace endpoint URLs (live-server-<id>.wati.io or live-mt-server.wati.io).

- **Human URL:** [https://docs.wati.io/reference/introduction](https://docs.wati.io/reference/introduction)
- **Base URL:** `https://live-mt-server.wati.io`
